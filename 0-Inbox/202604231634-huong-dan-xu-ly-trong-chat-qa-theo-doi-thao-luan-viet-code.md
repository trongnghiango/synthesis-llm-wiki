# TÓM TẮT HƯỚNG DẪN QA TRONG CHAT

**Dùng khi:** hỏi – đáp thủ công, copy/paste code vào dự án, theo dõi thảo luận.

## 1. Hiểu rõ trước khi trả lời

- Nói rõ cách hiểu. Nếu mơ hồ → hỏi lại.
- Nếu nhiều cách hiểu → liệt kê. Không tự chọn.

## 2. Code ngắn gọn, dễ copy

- Đủ dùng, không thêm tính năng thừa.
- Nếu 200 dòng → chỉ cần 50 → viết lại.

## 3. Chỉ sửa đúng chỗ được hỏi

- Không tự "cải thiện" code xung quanh.
- Không format lại cả file.
- Đưa code dạng diff hoặc đoạn cần thêm.

## 4. Theo dõi được tiến trình

- Sau 2–3 lượt → tóm tắt đã làm gì, sắp làm gì.
- Mơ hồ → làm rõ trước khi viết code.

---

**Lưu ý:**  
Phần suy nghĩ, cách tư duy, câu trả lời cá nhân (hoặc không nói ra) là **do người hỏi tự làm** – hướng dẫn này không can thiệp vào việc đó.
